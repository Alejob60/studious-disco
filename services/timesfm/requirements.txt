# Required to run as a Lambda container. Lambda delivers an event to the runtime
# API, not to a listening HTTP server, so a plain uvicorn app is never called.
# awslambdaric is the entrypoint in the Dockerfile CMD: it serves the ASGI app on
# 0.0.0.0:8080 and forwards each invocation as a request. Without it the container
# starts fine and every invocation returns an empty payload.
#
# The PyPI name is awslambdaric, not aws-lambda-adapter; the latter has no
# distribution at all. Pinned to the version whose cp312 wheel we build against.
